# まもってポン！（試作版）

**〜あそんで まなぶ ぼうさい〜**（旧名：ぼうさいポン！）

子どもが「ぽちっ」と押して、かわいいキャラクター「ポン」と一緒に災害時の初期行動を学ぶ防災学習アプリの試作品です。

**▶ ウェブで遊ぶ：** https://asuka-create.github.io/bousai-pon/

## できること
- **れんしゅう**：じしん・おおあめ・つなみ・かじ の行動を、絵と声で1つずつ確認（終わるとバッジ）
- **ぼうさいゲーム**：2択クイズ（10問から毎回5問）
- **いま こまっている**：まず身を守る行動を表示（ゲーム演出なし）
- **ぼうさいマンガ**：ポンと なかまたちの おはなし（5話・さいごに クイズ）
- **じゅんび**：ひなんリュックの チェックリスト
- **わたしの こと**：こまったときに おとなに みせる カード（にがてな こと・おねがい）
- **れんらく**：おうちの人への でんわ、119／110 の あんない
- **にげる ばしょ**：保護者が とうろくした 集合場所・避難場所の 確認。相模原市の場所を選んだ場合は「じしん ⭕／おおあめ ✖」のように、どの災害で使えるかを表示（未登録時は架空の練習地図）
- **おうちの人・せんせいへ**：長押しで開く 保護者メニュー（カード・連絡先・避難計画の登録、相模原市の避難場所・避難所からの選択）
- **せってい**：声 ON/OFF・速さ、やさしい表示（動きを減らす）、文字の大きさ、説明の量

設定・バッジ・登録内容は端末内（localStorage）にのみ保存し、インターネットには送信しません。

## 相模原市の避難所データ
- `shelters-sagamihara.js`：相模原市の指定緊急避難場所・指定避難所 168か所（うち指定避難所 105か所）
- 出典：国土地理院「[指定緊急避難場所・指定避難所データ](https://www.gsi.go.jp/bousaichiri/hinanbasho.html)」（相模原市登録分、データ更新日 2026-07-03、取得日 2026-11-23）を加工して作成
- 指定緊急避難場所は災害の種類（地震・洪水・崖崩れ等・大規模な火事・内水氾濫）ごとに指定されています。アプリでは、選んだ場所がどの災害に対応しているかを表示します。
- **ご利用上の注意**：本データは市町村が登録した情報で、最新でない場合や未掲載の場合があります。最新かつ詳細な状況は必ず相模原市に確認してください。福祉避難所のデータは含まれていません。
- データを新しくするときは、国土地理院のダウンロードサイトから相模原市（コード 14150）の CSV を取得し、`tools/build_shelters.py` で変換し直して `sw.js` の `VERSION` を上げてください。

## 動かし方
`index.html` をブラウザで開くだけで動きます（ビルド不要）。

## オフライン対応（PWA）
- 公開URLを一度ネットにつないで開くと、端末に保存され、そのあとは電波がなくても使えます。
- スマホの「ホーム画面に追加」で、アプリのように起動できます。
- ファイル構成：`manifest.webmanifest`（アプリ情報）、`sw.js`（オフライン保存の仕組み）、`icon-*.png` / `icon.svg`（アイコン）
- **ファイルを更新したら `sw.js` の `VERSION` を上げてください。** 上げないと、古い保存データが使われ続けることがあります。

## ⚠️ ご注意
- これは学習用の試作品です。公的な避難指示・緊急地震速報の代わりにはなりません。
- 災害時は自治体・気象庁・周囲の大人の指示を確認してください。
- 災害別の行動の文言は教材用の案であり、防災の専門家・自治体による監修が必要です。
- 地図・避難場所はすべて架空です。位置情報・本物の避難所データ・経路検索は未実装です。
